# Memory Matching Game in C++

This project is a console-based Memory Matching Game created in C++.

The game allows the user to choose a category, board size, and wait time after incorrect matches. It uses file input, arrays, random card shuffling, loops, functions, and basic input validation.

## Features

- Category selection: Art, Math, or Universe
- Board size options: 4x4, 6x6, or 8x8
- Random card shuffling
- File input using `.txt` files
- 2D arrays to store the board
- Input validation
- Move counter

## Technologies Used

- C++
- File handling with `fstream`
- Arrays and 2D arrays
- Loops and functions
- Randomization with `rand()` and `srand()`
- Console input and output

## How to Run

1. Download or clone the repository.
2. Make sure the `.txt` files are in the same folder as the `.cpp` file.
3. Compile the C++ file.
4. Run the program in the terminal.
